7 Network & reading

The public surface is one gRPC service, and most of it is mirrored to HTTP/JSON. This chapter covers the bytes a worker and a client exchange: framing, the RPCs of the specimen run, task tokens, sticky execution, and how history is read back.

7.2 Framing on the wire

gRPC runs over HTTP/2. Each unary call is a HEADERS frame (:path = /temporal.api.workflowservice.v1.WorkflowService/StartWorkflowExecution, content-type: application/grpc, plus the Temporal metadata of §6.1) followed by DATA frames carrying one Length-Prefixed-Message: a 1-byte compressed flag, a 4-byte big-endian length, then the protobuf body. Temporal adds nothing to this envelope.

Size ceilings: the Go SDK's client accepts messages up to defaultMaxPayloadSize = 128 MiB ({{SDK:internal/grpc_dialer.go#L56-L57}}), and internode clients use the same 128 MiB ({{T:common/rpc/grpc.go#L42-L43}}). The binding limits are the per-payload and per-history limits of §8.1, which are far smaller.

7.3 Starting an execution

The response carries a Link.WorkflowEvent (#4 → #1) that points at (namespace, workflow_id, run_id, event_ref{event_id:1, event_type:STARTED}). Links are how Nexus and callbacks cross-reference executions. The same structure can be attached to events (HistoryEvent.links, #302).

7.4 Polling and the task token

Workers long-poll. The frontend holds a PollWorkflowTaskQueue open until matching supplies a task or the poll times out. After the first WFT, the specimen worker polled its sticky queue, which is private to the process and holds its cached workflow state:

The response bundles an opaque task_token, the execution, and history. For a non-sticky poll that is the full history. For a sticky poll it is only the events since the worker's last completed WFT.

The task token is a plain, unencrypted temporal.server.api.token.v1.Task ({{T:proto/internal/temporal/server/api/token/v1/message.proto#L39-L56}}). Treat it as opaque, but it is not secret: it names the namespace, execution and scheduling coordinates, and the server re-validates all of them against mutable state on respond. A stale token, one with the wrong scheduled_event_id, attempt or started_event_id, gets NotFound. clock is a vector clock (shard_id, task-ID clock, cluster_id) that lets history reject responses that arrive after a shard moved.

7.5 Completing a workflow task

Three fields in this request control what the server does next:

  • sticky_attributes (#4). The worker registers vm:bd9b0888-… with schedule_to_start_timeout = 5 s. Subsequent WFTs go to that queue (event 8's task_queue.kind = STICKY, [[fig:fig-hnode06]]). If the worker does not pick up a task within 5 s, the server reschedules it on the normal queue orders with full history.
  • request_eager_execution on the command. The worker asks for the activity task to be returned inline in the response instead of dispatched through matching. The specimen got it: the response below carries the activity task in activity_tasks, with started_time equal to event 6's timestamp. The concurrent PollActivityTaskQueue returned an empty response (0 B).
  • return_new_workflow_task (#5). This allows the server to return the next WFT inline if one is already due, saving a poll round-trip.

7.6 Reading history and results

A client waiting for a result does not page through the whole history. It long-polls with wait_new_event = true and history_event_filter_type = CLOSE_EVENT (2), and the server responds only once the close event exists. Full reads page by events with maximum_page_size. The frontend default is frontend.historyMaxPageSize = 256 ({{T:common/primitives/constants.go#L21}}), and a next_page_token encodes the position. The response also has a raw_history form (repeated DataBlob) that returns stored batches without decoding. That is the SQL history_node.data of Chapter 4 passed through.

Reading tip To inspect bytes yourself, temporal workflow show --output json gives protojson. For wire bytes, reuse this repository's approach: a unary client interceptor that marshals req/reply ({{SDK:converter/grpc_interceptor.go}} shows the SDK's own payload-rewriting interceptor pattern).
